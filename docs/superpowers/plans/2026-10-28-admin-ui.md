# 管理端界面与文件编辑流程改版

依据用户 2026-10-28 的明确要求，在既有业务规格上改善管理端。仅修改管理端，不改变 API、数据库、桌面端或发布规则。

## 界面方案

使用 shadcn-vue 官方 Vite 接入流程，统一按钮、输入、对话框、表格和状态。按用户最新反馈改用中性灰黑主题，采用浅色工作区、固定侧栏与紧凑工具栏；复用客户端 Logo，压缩 Skill 页头和版本提示间距。仅支持桌面布局，工作区最小宽度 1200px；移除移动端断点、导航折叠和响应式单列布局，包括基础控件中的移动端字号与排列。文件树和清单仍可由用户主动收起。

游戏管理采用列表与独立编辑对话框；Skill 列表支持名称搜索、游戏筛选（全部、通用、具体游戏），并通向独立新增和编辑路由。创建后名称、类型和绑定仍不可变。

文件编辑工作区由可展开的文件树、Monaco 编辑器及清单/版本面板组成。新 Skill 默认生成兼容现有格式的 `SKILL.md`。支持任意 UTF-8 文本文件、嵌套路径、重命名、删除、语法高亮与安全的 Markdown 预览；二进制原字节保留并提供下载。文件路径禁止越界和相互覆盖。未保存修改在离开、替换文件或加载其他版本前提示确认。清单、版本与游戏关联仍保存在 D1，zip 不增加 registry。

组件边界：`AdminLayout` 负责导航；`SkillCatalog` 负责列表；新增/编辑 view 负责路由与加载；`SkillEditor` 与 `useSkillWorkspace` 编排清单和版本操作；`SkillIdentityForm` 负责创建信息；`SkillFiles` 编排文件工作区；`FileTree` 只负责目录导航；`CodeEditor` 只管理 Monaco 生命周期；`MarkdownPreview` 只渲染经过净化的 Markdown。状态由 composable 和明确的 props/emits、defineModel 传递。

## 实施与验证记录

官方创建的 Vite+ Vue 项目保持不变，按用户指定的 [Vite 接入文档](https://www.shadcn-vue.com/docs/installation/vite) 执行 `pnpm dlx shadcn-vue@latest init --defaults --base-color neutral --yes` 与 `pnpm dlx shadcn-vue@latest add button input textarea dialog tabs resizable --yes`，生成组件源码和 `components.json`。首次 alias 检查失败后补齐根 tsconfig；CLI 调用 Corepack 的 pnpm 版本与现有 workspace 不一致，修正本机 Corepack 版本后完成初始化。没有重建项目或替换原有 workspace。

新增回归先失败再实现：文件工具与筛选缺失、默认入口与草稿状态缺失、取消退出却清除凭证、取消导航却覆盖页面标题。集成测试另外发现创建后跳转被离开保护误拦截，修正后验证新建时的文件内容完整保留。原有页面测试随新的对话框与路由结构更新，继续覆盖权限失败、游戏标识不可改、二进制再发布与单次发布请求。Monaco 在组件测试中仅替换编辑器边界，其真实输入、语法高亮和 worker 由浏览器验证。

最终命令（仓库根目录）：

```powershell
pnpm --dir apps/admin exec vp fmt src vite.config.ts tsconfig.json components.json --write --threads=2
pnpm --dir apps/admin exec vp lint src --vue-plugin --deny-warnings --threads=2
pnpm --dir apps/admin exec vue-tsc --build
pnpm --dir apps/admin exec vp test run --maxWorkers=2 --reporter=dot
$env:RAYON_NUM_THREADS='2'
$env:TOKIO_WORKER_THREADS='2'
pnpm --dir apps/admin exec vp build
pnpm --filter server exec wrangler deploy --dry-run --config ../admin/wrangler.jsonc
git diff --check
```

结果：36 项测试通过、0 失败；格式、lint、类型检查及生产构建退出码 0；管理端 Worker dry-run 读取 152 个静态资源并打包成功。Monaco 的编辑器与语言 worker 延迟加载，构建仍有大 chunk 提示。初次不限并发的格式化/构建曾因 Windows 内存、线程资源不足失败，限制线程并暂时停止本次 Vite 服务后重试通过，随后已恢复本地服务。
